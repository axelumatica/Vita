Surface & motion rules ("Anti-Vibecode Engineering")

An ADHD brain has a hyper-tuned "clutter radar." Misaligned margins, jank, or inconsistent easing reads as untrustworthy and causes immediate app abandonment — so these are non-negotiable, not nice-to-haves.

RuleSpec
Corner radius16px (small components) / 24px (cards) — soft, tactile, never sharp
ElevationNo hard drop shadows. Only rgba(255,255,255,0.03–0.05) inset top-edge highlight to simulate lift
Transitions60fps deterministic, ease-in-out cubic-bezier, 200–250ms. No jank, ever, on the UI thread
Lior PulseActive/listening state emits a soft cream/navy glow (blur 20px) pulsing at breathing rhythm

Anti-hallucination extraction rules

RuleBehavior
Literal FirstA Task is extracted ONLY from explicit action verbs / future intent ("I need to…", "remind me to…"). Doubt or emotion → always Journal, never Task.
Confidence gateBelow 90% extraction confidence → saved as a neutral raw note with zero arbitrary tags, rather than guessing.
Staging areaNothing writes to the Vault silently. Everything sits in the Scratchpad for 1-tap confirm / swipe-to-discard first.
No creative summariesThe user's exact words are preserved verbatim in Journal entries — Lior never reframes them into a clinical-sounding paraphrase.
Project clusteringAuto-cluster into a Project Hub only above 80% semantic correlation; below that, ask via a discreet inline Yes/No prompt.

No system sounds anywhere — precision haptics only, so the app stays silent-safe in any environment (chosen explicitly over haptics+sound).

Ethical gamification (Neuro-Dopamine Loop)

PrincipleWhat it replaces
Visual uncluttering as rewardNot points/badges — completing tasks makes the UI emptier & calmer, which is the reward
Zero-streak-safeNo streak counters that can be "lost." 4 days away → "Welcome back. Where do we start today?"
Thumb-zone law (Fitts's Law)All primary actions live in the bottom third of the screen — reachable without repositioning grip
Modified Zeigarnik reliefCompleted tasks visually dissolve (color fade) instead of just vanishing — gives the brain an explicit "closure" signal

Crisis detection pipeline

Text/voice input → local NLP scans for overload markers (keywords: "too much", "can't do this", "stuck"; also short/incoherent sentence structure) + local prosody scan (rapid breathless speech, anomalous long pauses). If the overload score crosses threshold → task staging is auto-suspended and the UI transitions straight to Emergency Mode's two soft-trigger options, without the user needing to find the SOS button themselves. Explicitly NOT biometric/camera-based — text & voice content only, fully on-device, nothing leaves the phone for this check.

Dev workflow (Claude Code + OpenRouter, no auto-compact loops)

StepWhat to do
1. Isolate old codeTreat the previous codebase as read-only reference in a sibling folder — never let Claude Code scan it wholesale
2. One module per sessionNever ask for "the whole app" — one Rust file or one screen per prompt
3. Validate, don't eyeballcargo check for Rust, npx tsc --noEmit for TS — both run in ~1s and catch nearly everything before it hits the phone
4. Wireless deployPair the phone once via adb pair / adb connect over Wi-Fi, then npx expo start — hot-reload <1s, no cable needed again
5. Hard context resetAfter each successful git commit, run /compact or start a fresh terminal session to prevent auto-compacting mid-task

⚠ Architecture pivot — flagged for the record

Mid-brainstorm the project deliberately dropped two earlier "non-negotiable" pillars in favor of build speed: on-device SLM execution (Whisper.cpp/llama.cpp) and hardware-level SQLCipher encryption. The current direction uses plain SQLite + OpenRouter cloud calls for the Lior engine, with encryption/security to be revisited later. The UX/UI specs on every other screen in this file (privacy framing, "Local Engine" badges, encryption copy) reflect the original local-first vision — reconcile this before implementation, since several on-screen strings (e.g. "Zero cloud, zero accounts") currently promise more than the pivoted architecture delivers.
