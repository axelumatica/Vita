DATA STORAGE SCHEMAS, ENCRYPTION & RECOVERYLocal SQLCipher Schema (On-Device Storage)SQL-- Vault Entries Master Table
CREATE TABLE vault_entries (
    id TEXT PRIMARY KEY,
    type TEXT NOT NULL, -- 'TASK', 'DIARY', 'NOTE', 'VOICE'
    title TEXT,
    content_raw TEXT NOT NULL,
    content_formatted TEXT,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL,
    is_archived INTEGER DEFAULT 0,
    project_cluster_id TEXT,
    FOREIGN KEY(project_cluster_id) REFERENCES project_clusters(id)
);

-- Task Breakdown & Sub-Step Table
CREATE TABLE task_steps (
    id TEXT PRIMARY KEY,
    parent_task_id TEXT NOT NULL,
    step_description TEXT NOT NULL,
    is_completed INTEGER DEFAULT 0,
    execution_order INTEGER NOT NULL,
    FOREIGN KEY(parent_task_id) REFERENCES vault_entries(id) ON DELETE CASCADE
);

-- Project Clusters (Auto-Hub)
CREATE TABLE project_clusters (
    id TEXT PRIMARY KEY,
    cluster_name TEXT NOT NULL,
    confidence_score REAL NOT NULL,
    created_at INTEGER NOT NULL
);

-- Vector Embeddings (Local SQLite Vector Extension)
CREATE TABLE vault_embeddings (
    entry_id TEXT PRIMARY KEY,
    embedding_blob BLOB NOT NULL,
    FOREIGN KEY(entry_id) REFERENCES vault_entries(id) ON DELETE CASCADE
);
Encryption & Disaster Recovery SpecificationHardware Security: SQLCipher DB encrypted via Argon2id key derived from the Master Password and bound to Android StrongBox / Keystore.  Manual Export Format (.vita): Single-click generation of an encrypted, compressed archive containing DB entries, vector indexes, and raw audio files. Re-encrypted using a user-specified Master Export Passphrase. Zero unauthorized background cloud synchronization.  8.
